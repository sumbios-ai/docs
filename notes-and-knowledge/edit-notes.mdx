You can also add labels, set how important the note is, and attach documents, when you see those options.

## Where to find it

In the Library tab, open a note or create a new one to start writing.

## What you can do

- Change the title and the text, then choose Save when it appears.
- Use the attach or upload option to add files of a type O accepts.
- Open Note Properties to change details such as labels and importance.
- Use bulk document upload to add several accepted files at once.

## How to use it

- Wait until the note has finished saving before you leave it.
- Before you upload, check which file types and sizes are allowed.
- Read any information taken from a file or created automatically before you add it to the note.
- Before you remove an attachment, check whether it is used anywhere else.

<Note>
**Good to know.** The app only accepts files of the allowed types and within the upload limits. Don't attach confidential material unless your workspace allows it.
</Note>
