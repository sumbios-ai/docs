You can also add labels, choose its importance, and attach documents when those options are available.

## Where to find it

Open or create a note from the Library tab to start writing.

## What you can do

- Edit the title and body, then use Save when the editor presents it.
- Use the attachment/upload action to add supported files.
- Open Note Properties to change details such as labels and importance.
- Use bulk document upload for multiple supported files.

## How to use it

- Wait for the save state to complete before leaving the note.
- Check which file types and sizes are allowed before uploading.
- Review extracted or generated information before applying it to a note.
- Remove an attachment only after checking whether it is referenced elsewhere.

<Note>
**Availability and privacy.** Upload limits and supported types are enforced by the interface. Do not attach confidential material unless your workspace permits it.
</Note>
