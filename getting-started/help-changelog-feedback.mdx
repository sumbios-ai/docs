Changelog lists published product updates. Feedback opens the Sumbios feedback site.

## Where to find it

Open Help, Changelog, or Feedback from the sidebar.

## What you can do

- Search Help by feature or action, then select a result.
- Browse Help topics when you do not know the exact term.
- Read Changelog entries for product changes.
- Use Feedback to describe a problem or suggest a change.

## How to use it

- For a useful issue report, include the page, steps, expected result, actual result, and approximate time.
- Remove passwords, tokens, and private member details before submitting feedback.

<Note>
**Availability and privacy.** Help search covers published articles only. Feedback opens an external site; its availability and policies are governed there.
</Note>
