Help has articles you can search. Changelog lists the product updates Sumbios has published. Feedback opens the Sumbios feedback website.

## Where to find it

Open Help, Changelog or Feedback from the side menu.

<Frame caption="Help">
  <img src="/images/getting-started/help.png" alt="The Help page: quick page guides and help topics" />
</Frame>

## What you can do

- Search Help for a feature or something you want to do, then select a result.
- Browse the Help topics when you are not sure what to search for.
- Read Changelog to see what has changed in O.
- Use Feedback to describe a problem or suggest a change.

## How to use it

- When you report a problem, say which page you were on, what you did, what you expected, what happened instead, and roughly when.
- Before you send feedback, remove any passwords, access codes and private details about people.

<Note>
**Good to know.** Help search only covers published articles. Feedback opens a separate website, which sets its own policies and decides when it is available.
</Note>
