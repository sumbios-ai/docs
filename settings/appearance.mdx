Choose a light or dark appearance, try a color theme, and adjust the font size. You can also choose how side panels behave and whether to show a daily quote.

## Where to find it

Open Settings from the user/application menu and choose Appearance.

<Frame caption="Settings → Appearance">
  <img src="/images/settings/appearance.png" alt="Interface mode and visual style" />
</Frame>

## What you can do

- Choose Light, Dark, or System.
- Choose a visual style and filter color themes by category.
- Adjust font size with the slider.
- Set Dock and Daily Quote preferences; use Reset to restore defaults.

## How to use it

- Try one change at a time and see how it looks in the preview or on the page.
- Use the color theme category buttons (All, Minimal, Colorful, Branded, Creative, Dark) to find a theme.
- Unpin on Close is experimental: closing a pinned side-panel tab moves it into a floating window. This does not apply to the Assistant.

<Note>
**Availability and privacy.** Theme choices depend on the current application options. Appearance changes do not change workspace data.
</Note>
