You can paste it or upload a PDF, DOCX, Markdown, or text file (up to 10 MB) to extract text for review. A last-saved date appears below the editor.

## Where to find it

Open Settings → Résumé when the feature is enabled for your account.

<Frame caption="Settings → Résumé">
  <img src="/images/settings/resume.png" alt="Upload or paste your base résumé" />
</Frame>

## What you can do

- Paste or edit your base résumé, then choose Save résumé.
- Upload a supported file to replace the draft text, review the extraction, then save it.
- Choose Delete base résumé to remove the saved base text.
- Use /resume in Ask O with a pasted or attached job description for a tailored draft.

## How to use it

- Check extracted names, dates, achievements, and contact details before choosing Save résumé.
- Tailored drafts are separate from your base résumé and professional profile.
- Deleting the base résumé leaves existing conversation drafts in place; delete those conversations separately if needed.

<Note>
**Availability and privacy.** This section is hidden when résumé tailoring is not enabled. Résumés contain personal information; include only details you want O to use and share a tailored draft only after reviewing it.
</Note>
