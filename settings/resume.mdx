Paste it in, or upload a file and O pulls out the text for you to check. You can upload a PDF, Word (DOCX), Markdown or plain text file of up to 10 MB. Below the editor you'll see when it was last saved.

## Where to find it

Open Settings → Résumé. You'll only see it if the feature is turned on for your account.

<Frame caption="Settings → Résumé">
  <img src="/images/settings/resume.png" alt="Upload or paste your base résumé" />
</Frame>

## What you can do

- Paste or edit your base résumé, then choose Save résumé.
- Upload one of the file types above to replace the text in the editor, check the text O pulled out, then save it.
- Choose Delete base résumé to remove your saved base résumé.
- In Ask O, use /resume with a job description you paste or attach, and you'll get a draft tailored to that job.

## How to use it

- Before you choose Save résumé, check the names, dates, achievements and contact details O pulled out.
- Tailored drafts are kept separate from your base résumé and your professional profile.
- Deleting your base résumé doesn't remove the drafts already in your conversations. Delete those conversations separately if you need to.

<Note>
**Good to know.** You won't see this section if résumé tailoring isn't turned on. A résumé holds personal information, so include only the details you want O to use, and read a tailored draft before you share it.
</Note>
