Node Name Display (a node is a dot on the map) lets you show first names or full names. Sub-label adds a second line under the name, such as a job title, company or location, or you can leave it blank.

## Where to find it

Open Settings → Network Map.

<Frame caption="Settings → Network Map">
  <img src="/images/settings/network-map.png" alt="The Network Map section: Node Name Display and Sub-label options" />
</Frame>

## What you can do

- Choose whether the map shows each person's first name or full name.
- Choose the extra detail shown under larger or highlighted names, or select None to show the name only.

## How to use it

- Go back to Network to see how the names and labels look.
- To change what the map shows, use the network choices and view options on the Network page. These settings only change the labels.

<Note>
**Good to know.** These settings only change how the map looks. They don't change the information about your network or what you share with others.
</Note>
