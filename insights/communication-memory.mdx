When available, you can bring in more history or choose which conversations to include.

## Where to find it

Open Communication Memory from Insights or /intelligence/communications.

## What you can do

- Check which accounts are connected and whether their history has finished loading.
- Use the history import option to bring in conversations from a connected account, when available.
- Choose which conversations to include using the filters.
- Review connected sources through Settings → Connections.

## How to use it

- Before importing, read which conversations will be included and what permission you are giving.
- Use filters to keep only the history you want O to use when helping with relationships.
- Check whether loading has finished and whether any errors are shown. Some conversations may still be missing.

<Note>
**Availability and privacy.** Communication data can be sensitive. Only import sources you authorize, and review filtering and retention choices. A missing record is not evidence that communication did not happen.
</Note>
