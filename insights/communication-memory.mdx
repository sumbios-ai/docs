---

When the option is there, you can also bring in more history or choose which conversations to include.

## Where to find it

Open Communication Memory from Insights.

<Frame caption="Insights → Communication Memory">
  <img src="/images/insights/communication-memory.png" alt="Communication Memory before any conversations are connected" />
</Frame>

## What you can do

- Check which accounts are connected and whether their history has finished loading.
- When it's offered, use the history import option to bring in conversations from a connected account.
- Use the filters to choose which conversations to include.
- Review the accounts you connected in Settings → Connections.

## How to use it

- Before you import, read which conversations will be included and what permission you are giving.
- Use the filters to keep only the history you want O to use when it helps you with your relationships.
- Check that loading has finished and look for any error messages. Some conversations may still be missing.

<Note>
**Privacy.** Your conversation history can be sensitive. Only import from accounts you have approved, and check your filter choices and how long history is kept. If a conversation is missing here, that doesn't mean it never happened.
</Note>
