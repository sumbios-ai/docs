See which requests are Active, Paused, or Fulfilled, and review any suggested members. If you have no requests yet, you can ask O for help getting started.

## Where to find it

Open Shared Introductions from the Insights overview, or visit /intelligence/network-needs.

## What you can do

- Read what you asked for, when you asked, and where the request stands.
- Explore suggested members and check what has happened with each suggestion.
- If the list is empty, choose Ask O for an introduction to start from Home.

## How to use it

- Before reaching out, check that the introduction is still something you want.
- These are your requests. A suggested member has not necessarily agreed to be introduced.
- Offer an introduction only when you can verify the fit and have permission.

<Note>
**Availability and privacy.** Matches depend on the available shared network and do not imply consent or willingness to connect. The page is a status view, not a place to edit another member’s request.
</Note>
