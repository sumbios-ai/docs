See whether each request is Active, Paused or Fulfilled, and look at any people suggested for it. If you have no requests yet, you can ask O to help you get started.

## Where to find it

Open Shared Introductions from the Insights overview.

## What you can do

- See what you asked for, when you asked, and where each request stands.
- Look through the suggested people and see what has happened with each suggestion.
- If the list is empty, choose Ask O for an introduction to start one from Home.

## How to use it

- Before you reach out, check that you still want the introduction.
- These are your requests. A suggested person hasn't necessarily agreed to be introduced.
- Only offer an introduction when you can confirm it's a good fit and you have permission.

<Note>
**Good to know.** Suggestions depend on what is available in the shared network. A suggestion doesn't mean the person has agreed to connect, or wants to. This page shows where requests stand. You can't use it to edit someone else's request.
</Note>
