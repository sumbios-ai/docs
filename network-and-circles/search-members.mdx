Open a profile to explore someone’s work, education, connections, and the sources behind those details.

## Where to find it

Open Network and use the search field and filters above the map or list.

## What you can do

- Search by name or the details supported by the visible filters.
- Sort list results using the available sort selector.
- Choose a member in the list or a dot on the map to open their profile.
- Use Contact Import when you need to add supported contact data.

## How to use it

- Try a distinctive name or organization if a broad search returns too much.
- Check that you have the right member and read the sources before making changes or reaching out.
- Clear your search and filters to see the full network you selected again.

<Note>
**Availability and privacy.** The results depend on the information in O and the networks you have selected. Two members may have similar names, so check the profile before making changes or reaching out.
</Note>
