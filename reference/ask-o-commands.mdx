---
title: "Ask O commands"
description: "Every command you can type with a slash in the Ask O message box, and the keys that help you get around."
---

In the Ask O message box, type `/` to see the commands, or `@` to mention a person, company, note or Circle. Picking a command tells O exactly what kind of help you want. You can always write in your own words instead: [What you can ask O](/reference/what-you-can-ask) has an example for each thing O can do.

## Explore

| Command | What it does |
|---|---|
| `/entity` | Look up a person, company, note, or Circle |
| `/people` | Find people in your network |
| `/person` | Look into one person in depth |
| `/company` | Find companies or look into them |
| `/company-info` | Look into one company in depth |
| `/cluster` | Look at the groups of closely connected people in your network |
| `/growth` | See how your network has grown |
| `/memory` | Search the documents and facts saved in O |
| `/content` | Search your messages, emails and other content |
| `/note` | Search notes about a person, company or topic |
| `/news` | Get news about your network |
| `/research` | Research a person or company in depth |
| `/websearch` | Do a quick search of the web |

## Prepare

| Command | What it does |
|---|---|
| `/compare` | Compare people side by side |
| `/chart` | Make a chart |
| `/skill-gap` | Find skills your network is missing |
| `/intro` | Find people you know who can introduce you to someone |
| `/matches` | Find good matches for an introduction |
| `/intro-draft` | Draft an introduction |
| `/outreach` | Draft a message to someone |
| `/export` | Make a report you can export |
| `/resume` | Tailor your résumé to a job description. See [Résumé](/settings/resume). |

Drafts stay drafts until you decide. If you ask O to send an email or a WhatsApp message, or to book a meeting, it shows it to you first and sends it only when you confirm.

## Organize

| Command | What it does |
|---|---|
| `/add-to-circle` | Add people to a Circle |
| `/pipeline` | Build a talent pipeline: a list of people you might hire |
| `/remind` | Set a reminder. See [Reminders](/notifications-and-conversations/reminders). |

## Automate

| Command | What it does |
|---|---|
| `/list-integrations` | Show the accounts you have connected |

## Open a page

| Command | Opens |
|---|---|
| `/home` | Home |
| `/network` | Network map |
| `/circles` | Circles |
| `/friends` | Friends and groups |
| `/notes` | Notes |
| `/document-map` | Document map |
| `/discovery` | Discovery |
| `/notifications` | Notifications |

## Keys

| Keys | Where | What it does |
|---|---|---|
| `⌘ K` | Anywhere | Open search |
| `↑` `↓` | Search | Move through results |
| `↵` | Search | Open the selected result |
| `@` | Ask O | Mention a person, company, note or Circle |
| `/` | Ask O | Show the commands |
