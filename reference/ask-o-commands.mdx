---
title: "Ask O commands"
description: "Every slash command in the Ask O message box, and the keys that help you move around."
---

In the Ask O message box, type `/` to see the commands, or `@` to mention a person, company, note or Circle. Choosing a command tells O exactly what kind of help you want. You can always just write in your own words instead.

## Explore

| Command | What it does |
|---|---|
| `/entity` | Look up a person, company, note, or Circle |
| `/people` | Find people in your network |
| `/person` | Deep-dive into a person |
| `/company` | Find or analyze companies |
| `/company-info` | Deep-dive into a company |
| `/cluster` | Analyze network clusters |
| `/growth` | Analyze network growth |
| `/memory` | Search your document memory and saved facts |
| `/content` | Search messages, emails, and content |
| `/note` | Search notes about a person, company or topic |
| `/news` | Get news for your network |
| `/research` | Deep research about a person or company |
| `/websearch` | Quick web search |

## Prepare

| Command | What it does |
|---|---|
| `/compare` | Compare people side by side |
| `/chart` | Create a chart |
| `/job-match` | Match jobs to your network |
| `/skill-gap` | Analyze skill gaps in your network |
| `/intro` | Find a warm introduction path |
| `/matches` | Find introduction matches |
| `/intro-draft` | Draft an introduction |
| `/outreach` | Draft a message to someone |
| `/export` | Generate a report you can export |
| `/resume` | Tailor your résumé to a job description. See [Résumé](/settings/resume). |

Drafts stay drafts. O never sends anything for you; sending is always a separate step you take yourself.

## Organize

| Command | What it does |
|---|---|
| `/add-to-circle` | Add people to a Circle |
| `/pipeline` | Build a talent pipeline |
| `/remind` | Set a reminder. See [Reminders](/notifications-and-conversations/reminders). |

## Automate

| Command | What it does |
|---|---|
| `/list-integrations` | List your connected integrations |

## Open a page

| Command | Opens |
|---|---|
| `/home` | Home |
| `/network` | Network map |
| `/circles` | Circles |
| `/friends` | Friends and groups |
| `/notes` | Notes |
| `/document-map` | Document map |
| `/discovery` | Discovery |
| `/notifications` | Notifications |

## Keys

| Keys | Where | What it does |
|---|---|---|
| `⌘ K` | Anywhere | Open search |
| `↑` `↓` | Search | Move through results |
| `↵` | Search | Open the selected result |
| `@` | Ask O | Mention a person, company, note or Circle |
| `/` | Ask O | Show the commands |
